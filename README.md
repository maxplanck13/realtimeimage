# A Description of the Project
This project presents a Hardware-Integrated Digital Signal Processing (DSP) Console developed for real-time image manipulation through physical electronic controls and MATLAB-based digital processing. The system demonstrates the practical implementation of core concepts from Signals and Systems by integrating embedded hardware, analog signal acquisition, serial communication, and digital image processing into a single interactive platform.

The hardware section functions as the input acquisition layer of the system. An Arduino Uno is used as the central controller to continuously sample analog signals generated through three 10kΩ potentiometers configured as voltage dividers. Using the Arduino’s 10-bit Analog-to-Digital Converter (ADC), the continuous-time analog inputs are converted into discrete-time digital values ranging from 0 to 1023. Two tactile push buttons configured with internal pull-up resistors are incorporated to perform system-level operations such as image reset and saving processed outputs. The acquired digital data is transmitted to MATLAB using UART serial communication at a baud rate of 115200, ensuring low-latency and near real-time interaction between hardware and software.

The software section, implemented in MATLAB, acts as the DSP engine of the system. MATLAB continuously monitors and parses the incoming serial data stream, interpreting the values as discrete-time control signals. These signals are mapped to real-time image processing operations including brightness adjustment, contrast enhancement, and saturation control. Brightness is modified through pixel intensity offset manipulation, contrast is adjusted by scaling intensity distribution relative to the image mean, and saturation is controlled using RGB-to-HSV color space transformation techniques. A custom-developed Graphical User Interface (GUI) provides live visualization of the processed image, updating dynamically whenever the user interacts with the physical controls.

The project effectively bridges theoretical DSP concepts such as sampling, quantization, system response, and input-output relationships with practical implementation. By replacing conventional mouse-and-keyboard interaction with a custom tactile control console, the system demonstrates how embedded hardware can be integrated with sophisticated software algorithms to create an intuitive and interactive digital signal processing environment.
